# صفحة الهبوط - تطبيق عون

صفحة الهبوط الاحترافية لتطبيق عون (Quran Connect) جاهزة للنشر على Vercel.

## 🚀 النشر السريع

### الخطوة 1: تسجيل الدخول (مرة واحدة فقط)
```bash
cd C:\Aoun\quran_connect\landing-page
vercel login
```
سيتم فتح المتصفح - قم بتسجيل الدخول ثم ارجع إلى Terminal.

### الخطوة 2: النشر
```bash
vercel --yes
```

## ✅ ما تم إعداده

- ✅ `vercel.json` - إعدادات الأمان والأداء
- ✅ `package.json` - تعريف المشروع
- ✅ Git repository محلي
- ✅ جميع المسارات والملفات جاهزة

## 📦 الملفات

- `index.html` - الصفحة الرئيسية
- `styles.css` - التصميم
- `script.js` - التفاعلات
- `assets/aoun_v1.1.0.apk` - ملف التطبيق
- `assets/app_icon.png` - أيقونة التطبيق

## 🌐 بعد النشر

بعد النشر الناجح، ستحصل على رابط مثل:
- `https://aoun-landing-page.vercel.app`

يمكنك أيضاً ربط نطاق مخصص من إعدادات المشروع في Vercel Dashboard.
